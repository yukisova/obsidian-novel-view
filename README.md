# Novel View

Novel View 是面向长篇小说写作的 Obsidian 插件。它把小说组、卷章管理、设定资料、文字标记、查找替换和写作统计整合在同一套工作流中。

当前版本：`0.13.1`

## 主要功能

- 小说组管理；一个小说组就是一个普通文件夹。
- 卷、章节的新建、重命名、拖动和删除。
- 章节状态与字数统计。
- 设定组、标签、设定记录与详细设定文件。
- 文字标记：聚合正文中的同名标记，可添加说明、查看片段并跳转正文。
- 查找与替换：支持当前章节、本卷和全书。
- 世界观关键词高亮。
- 打字写作模式，以及纯粹、黑屋模式。
- 无缝模式：同一 NovelEditor 内加载当前章节及前后章，连续滚动编辑，章节间使用装饰分隔。
- 脚注、引用块和文章信息侧栏。
- 自动记忆每章写作位置。
- 页边距可自动适应或限制每行字符数。
- TXT 导入与导出。
- 小说组封面、简介与状态。

## 安装

1. 将 `main.js`、`manifest.json` 与 `styles.css` 放入 Obsidian 仓库的插件目录：

   ```text
   .obsidian/plugins/novel-view/
   ```

2. 在 Obsidian 的“第三方插件”中启用 Novel View。

## 快速开始

### 1. 创建小说组

在文件树中右击一个文件夹，选择“构建小说组”。

### 2. 打开文章列表

右击小说组文件夹，选择“打开文章列表”。左栏显示卷和章节。

### 3. 新建卷和章节

在文章列表空白处右击：

- “新建卷”创建子文件夹；
- “新建文章”创建章节；
- 章节会带有写作状态和章节编号。

### 4. 开始写作

小说组内的章节会进入独立的 NovelEditor 界面；普通非小说 Markdown 仍使用原生 MarkdownView。

进入方式：

- 点击小说组章节；
- 命令面板执行“Novel View: 打开 NovelEditor”；
- 在文章列表或工作台中点击章节；
- 在文章列表右击章节，选择“在新标签页打开（NovelEditor）”。

NovelEditor 隐藏 Obsidian 的视图头栏；标签和正文标题都显示当前章节名。

常用入口：

- 底部浮动工具栏：自动排版、插入图片、模式切换；
- 搜索按钮：打开查找与替换；
- 打字模式：当前编辑行居中；
- 右击选区：转换成对照组、添加文字标记、插入脚注或引用块。

### 5. 使用设定组

在左栏设定组列表中：

- 右击空白处新建设定组；
- 点击标签标题展开或折叠记录；
- 点击记录查看详情；
- 拖动记录调整顺序；
- 使用搜索框按设定记录名称筛选。

### 6. 使用文字标记

在正文中选中文字，右击并添加文字标记。

右侧“文字标记”面板会按标记名称聚合：

- 点击标题展开卡片；
- 查看标记说明和正文片段；
- 点击片段跳转到正文；
- 点击铅笔按钮编辑说明；
- 拖动卡片调整同一标记内的顺序。

## 首次安装与更新说明

插件首次安装后会显示欢迎说明；升级后会显示对应版本的更新说明。

说明文档会根据系统语言选择：

```text
INTRODUCE.cn.md
INTRODUCE.en.md
UPDATED.cn.md
UPDATED.en.md
```

中文系统使用中文文档，其他语言使用英文文档。

## 开发

要求 Node.js 20 及以上。

```bash
npm install
npm run check
npm test
npm run build
```

构建会把插件部署到默认 Obsidian 仓库；可用 `NOVELVIEW_PLUGIN_DIR` 指定目标目录。

## 目录

```text
src/
  app/          设置类型、首次说明
  core/         数据模型与纯函数
  editor/       CodeMirror 编辑器扩展
  features/     各功能视图
  legacy/       旧版兼容实现
  ui/           通用界面组件
tests/          单元测试
scripts/        测试与部署脚本
docs/           设计文档与说明文档
```

## 数据文件

- `novel.json`：小说组配置；
- `index.md`：设定组索引；
- 文章属性：章节状态、文字标记；
- `novelview-mark-notes.json`：文字标记说明；
- `novelview-mark-order.json`：文字标记顺序。

## 常见问题

### 文章没有进入 Novel View

确认文章所在文件夹中存在 `novel.json`，并且文章不是插件配置文件。

### 找不到文字标记

确认正文已经保存，标记区间仍然有效，并检查文字标记面板中的搜索词。

### 设定组为空

先在左栏设定组列表中新建设定组，再新建标签和设定记录。

### 如何重新查看说明

首次安装和版本更新时会自动显示说明；同版本不会重复弹出。
