# Novel View update

## Writing and reading

- New toolbar modes: pure and dark room; they can be combined with typing mode
- New seamless mode: continuous previous/current/next chapters in one view, with decorated boundaries and automatic saving
- New article info sidebar with a user-written summary, word count, text marks, control groups and footnotes
- New footnotes: insert from the context menu; the body shows only the number, and notes are edited inline in the article info sidebar
- New quote blocks with compact Markdown-style rendering
- Each chapter remembers the last writing position and restores it on reopen
- New page margin setting for automatic width or a fixed number of characters per line
- Setting record descriptions now render single-level ordered and unordered lists

## Other

- README and design documentation are now Chinese-only
- A welcome or update card is shown after installation or upgrade
- Obsolete code paths were removed and the module layout was simplified

## Recommendation

After upgrading, use the "Open NovelEditor" command to enter the standalone writing view.
