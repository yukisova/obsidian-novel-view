# 欢迎使用 Novel View

Novel View 是一个面向长篇小说写作的 Obsidian 插件，把章节管理、设定资料、文字标记、查找替换和写作统计放在同一个工作流里。

## 从这里开始

1. 在文件树中右击一个文件夹，选择“构建小说组”。
2. 点击“文章列表”进入小说工作区。
3. 在左栏创建设定组，在右栏查看文字标记。
4. 小说组章节会进入独立的 NovelEditor 界面；普通非小说 Markdown 保持原生。

## 主要能力

- 小说组、卷、章节管理；
- 章节状态与字数统计；
- 设定组、标签与设定记录；
- 文字标记与标记说明；
- 全章、本卷、全书查找与替换；
- 打字写作模式；
- TXT 导入与导出。

需要帮助时，可以查看本文档和插件内各面板的提示。
