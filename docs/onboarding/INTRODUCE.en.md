# Welcome to Novel View

Novel View is an Obsidian plugin for long-form fiction. It brings chapters, setting records, text marks, search and writing statistics into one workflow.

## Start here

1. Right-click a folder in the file explorer and choose **Build novel group**.
2. Open **Article list** to enter the writing workspace.
3. Create setting groups in the left sidebar and review text marks in the right sidebar.
4. Chapters in a novel group open in the standalone NovelEditor; normal non-novel Markdown files stay native.

## Main features

- Novel group, volume and chapter management
- Chapter status and word counts
- Setting groups, tags and records
- Text marks with notes
- Chapter, volume and book-wide search and replace
- Typing writing mode
- TXT import and export

For guidance, read this document and the hints inside each panel.
