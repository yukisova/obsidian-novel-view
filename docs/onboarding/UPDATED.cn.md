# Novel View 更新说明

## 编辑与阅读

- 工具栏新增纯粹模式和黑屋模式，可与打字模式同时启用；
- 新增无缝模式：同一界面连续加载前后章节，自动保存，章节间有装饰分隔；
- 新增文章信息侧栏，显示用户填写的内容概要、字数、文字标记、对照组和脚注；
- 新增脚注：右击插入，正文显示序号，说明直接在文章信息侧栏内联填写；
- 新增引用块：支持 `>` 引用语法，并使用更紧凑的引用排版；
- 编辑器会记住每章的写作位置，下次打开自动回到原处；
- 新增页边距设置，可选择自动适应或固定每行字符数；
- 设定记录介绍支持单级有序和无序列表。

## 其他

- README 与设计文档改为中文；
- 首次安装和更新时显示说明卡片；
- 清理旧功能残留代码，精简模块结构。

## 建议

升级后先打开一个章节，执行“打开 NovelEditor”进入独立写作界面。
