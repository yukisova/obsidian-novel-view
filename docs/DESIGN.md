# NovelView 0.6.21 设计说明

## 1. 数据与状态

- 小说组：非根目录文件夹 + `NovelSetting.md`。
- 文章：小说组内普通 Markdown。
- 章节状态属性：`novelview-state`，值支持 待写/草稿/大纲/修改中/已完稿（及英文别名）。
- 小说状态 `novelstate` 已删除；加载时清理旧属性。
- 描述 `描述` 属性、卷描述正文、浮动描述面板全部删除；加载时清理。

## 2. 文章列表

- 标题只显示小说名 + 正文数量。
- 左侧替换文件列表；标题栏返回图标；工具栏可见“返回”按钮。
- 章节行显示字数 + 状态。
- 多选：框选/Shift/Ctrl；多选禁止重命名。
- 右键：重命名（单选）、删除（批量）；无编辑描述。
- 新文章“无标题”，frontmatter 只写 `novelview-state: 待写`。
- 新卷“无名卷”，重名编号。

## 3. 小说模式状态卡

- 右上角状态卡显示字数 + 章节状态。
- 点击弹出状态菜单，写入 `novelview-state`。
- 状态改变后刷新文章列表和编辑器状态卡。
- 不再打开小说信息。

## 4. 小说组点击

- 点击小说组：打开/聚焦左侧文章列表。
- 若主区域已存在工作台：只更新 `workbenchFolderPath` 并刷新，不自动跳转。
- 若不存在：打开工作台。

## 5. 联动库

### 5.1 存储

- 配置文件：`<novel-group>/links.json`（不再使用 `link/` 文件夹）。
- 结构：

```json
{
  "group": { "联动组1": "#aa3311" },
  "link": [
    { "未命名.md": { "belong": "联动组1", "alias": ["你好"] } },
    { "~/仓库内引用.md": { "alias": ["你好hk"] } }
  ]
}
```

- 读取时清理目标文件已不存在的记录。
- 导入候选：仓库内任意 TFile，只要不属于小说组；支持非 Markdown 和插件文件。
- 路径：`~/` 仓库根；裸路径按当前卷、组根、旧 `link/` 回退。

### 5.2 UI

- 标题 + 分隔线 + 工具栏，样式与素材库一致。
- 无顶部工具栏；右键空白：新增联动组、导入联动文件。
- 组可展开/折叠；组不可嵌套；组/文件可拖拽、聚焦。
- 右键组/文件：编辑、重命名、删除。
- 重命名：行内输入。
- 编辑：无遮罩浮动面板；组只改颜色，文件只改别名，不弹对话框。
- 导入：悬浮树窗口，显示路径，可设置别名，Enter 依次确认。

## 6. 素材库

- 标题 + 分隔线；单图标。
- 空状态水印：“双击空白区域可导入图片”。
- 双击空白选择图片，写入 `<group>/src/`。
- 卡片提供“重命名”按钮，行内编辑；无卡片右键菜单。
- 打开/删除；无复制链接。

## 7. 链接关键词

- 沿用联动库 JSON 的 group/link 数据。
- 关键词：文件名去 `.md` + alias。
- 颜色来自 group；缺 belong 归默认组。
- `~/` 从仓库根解析；裸路径支持当前卷/组根/旧 link 文件夹。
- 编辑/阅读视图高亮，点击打开目标。

## 8. 清理

- 特殊页面（设定/人物/时间线/伏笔/大纲/灵感）全部移除。
- 旧 `novelview-type` 分类属性清理。
- 描述属性/正文清理。
- 小说状态属性清理。

## 9. 验证

- `npm run check`
- `npm test`（23 个测试）
- `npm run build`
- Mock smoke：5 个 View、1 个命令、文章列表、联动 JSON 根目录、工作台分组。

## 10. 已知限制

- 联动库保存的是仓库路径，实际文件删除后记录会在下次读取时清理。
- 导入只接受仓库已识别文件。
- 文章列表替换左侧文件列表；返回按钮恢复。
- 工作台卡片仍为空。


## 11. 0.6.21 补充

### 联动标签与样式

- 联动组只保存字体样式：normal/bold/italic/bolditalic/underline，不再保存组颜色。
- 联动文件增加可选 `tag`；每个文件最多一个标签。
- 标签颜色保存于 `tag[group][tag]`，作为关键词高亮色。
- 树结构：组 → 无标签文件 / 标签节点 → 标签内文件；组和标签均可展开/折叠。
- 多选逻辑常驻，无多选工具栏按钮；多选右键提供批量添加标签、批量删除。
- 组编辑只改字体样式；文件编辑只改标签、标签颜色、别名；重命名通过右键行内完成。
- 标签颜色预设红/橙/黄/绿/蓝/紫，并支持自定义颜色。

### 高级查找替换

- 入口移至小说模式浮动工具栏；旧标题栏按钮、工作台按钮、命令移除。
- 范围：全章/本卷/全书/联动库文件。
- 结果标题：查找结果 · 范围类型 · 小说组。
- 结果卡片可滚动、超宽省略；支持正则/大小写/全词。

### 格式设置

- 浮动工具栏新增设置按钮。
- 无遮罩窗口实时调整字体大小、行距、段距、首行缩进。
- 字体大小以 `--novelview-font-size` 应用于编辑/阅读视图。

### 验证

- 0.6.21 构建；23 个核心测试。

## 13. 0.6.21 自动排版规则

- 删除所有普通空行。
- 仅在以下块前后各保留一行空行：
  - 分隔线
  - 表格
  - 列表
  - 引用块
- 代码块内空行仍删除；代码内容不修改。
- 列表/引用块不再应用特殊行距、段距、首行缩进。
- 分隔线仅取消首行缩进，不应用块级特殊样式。


## 14. 0.6.21 导出清理

- 删除“导出”文件夹忽略逻辑。

- 删除未使用的旧 Search Panel、Search Results、素材选择 Modal、设置页、替换确认等孤立源码。


## 15. 0.6.21 渲染问题排查

- 现象：文章列表/文件列表切换时，左侧 Ribbon 偶尔被黑色背景覆盖，毛玻璃失效。
- 原因：自定义文章列表叶子叠加了 `contain: paint`、`isolation: isolate`、`z-index`，并额外覆盖了 workspace leaf/header 背景，形成额外合成层；Electron/Chromium 在 backdrop-filter 毛玻璃层与新合成层交叉时出现黑色 tile。
- 处理：移除 contain/isolation/position/z-index 与 leaf/header 背景覆盖；文章列表只保留单一不透明内容背景。
- 同时移除文章状态卡、浮动工具栏、TOC 的 backdrop-filter，改用不透明背景，避免额外 GPU 层。


## 16. 0.6.21 文章列表与浮动窗口

- 文章拖拽排序；`novelview-chapter` 保存章节号；`NovelSetting` 的 `novelview-volume-order` 保存卷顺序；分散卷显示 -1，其他卷 0 起。
- 多选文章批量拖拽；Cmd/Ctrl+Z 撤销移动/删除/重命名；Cmd/Ctrl+N 新建章节。
- 分散卷常驻；排序正/倒序按钮。
- 工具栏“导入与导出”菜单：TXT 导入、全组 TXT 导出。
- 自动排版清理段首/段尾空格与 Tab。
- 高级查找为全局浮动卡片，跨章节单例复用，范围随当前章节更新。
- 素材库/联动库优先复用右侧已有 Tab。
- 文章列表/素材库/联动库/工作台标题使用界面字体。


## 17. 0.6.21 ID 排序与拖拽预览

- 文章排序仅依据递增的 `novelview-id`，不再以文件名排序。
- 新建文章取当前文件夹最大 ID + 1。
- 拖到卷名：移动到该卷末尾并按顺序重分配 ID。
- 拖到文章之间：按插入位置重排 ID。
- 树中不显示文章/卷 ID。
- 拖拽预览：卷区域整块虚线高亮；文章之间显示插入线。
- 移除正序/倒序按钮。
- 插件声明为桌面端专用（系统文件对话框与 Node 文件系统）。


## 18. 0.6.21 细节修复

- 文章移动/排序期间暂停文章列表刷新，ID 重排完成后延迟一次渲染，消除抖动。
- 素材库、联动库标题下显示当前小说组。
- 联动导入窗口新增“加入”按钮，行为等同回车；别名输入框占位简化为“别名（可选）”。


## 19. 0.6.21 抖动修复

- 移动开始时取消失败的待渲染 rAF，记录冷却时间。
- 移动期间的 vault/metadata 事件只登记一次延迟刷新，不再中途重排 DOM。
- 移动结束后统一延迟渲染。
- 拖到卷名只给被移动文章分配递增 ID，不再重写目标卷所有文章 ID，减少元数据事件。
- 插入操作仍按目标顺序重编号，但整体合并为一次刷新。


## 20. 0.6.21 导入窗口按钮状态

- 未选择联动文件时，“加入”和别名输入框均禁用。
- 选中文件后才启用；取消选择或导入后重新禁用。
- 取消自动选中第一个文件，避免未选择也能操作。
